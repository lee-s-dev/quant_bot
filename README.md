# 🚀 QuantBot V4.0: 24/7 비트코인 스마트 무인 자동매매 시스템

QuantBot은 업비트(Upbit) API를 활용하여 비트코인(BTC) 시장을 24시간 감시하고, 수학적 지표에 기반해 자동으로 매수/매도 및 리스크 관리를 수행하는 파이썬 기반의 퀀트 트레이딩 봇입니다. 

단순한 수익 창출을 넘어, 철저한 **하락장 회피(필터링)**와 **변동성 기반의 자산 보호(ATR)**에 초점을 맞추어 설계되었습니다.

## 📈 핵심 매매 전략 및 보조지표 설명

QuantBot V4.0은 **Top-Down 방식(다중 타임프레임 분석)**을 사용하여 큰 추세를 먼저 확인한 후, 짧은 프레임에서 정밀하게 진입합니다.

### 1. 상위 추세 필터링 (1시간 봉 기준)
가짜 돌파(휩쏘)에 당하지 않고, 확실한 상승장에서만 매매하기 위한 안전장치입니다.
* **EMA (지수이동평균선, 20 & 50):** 단기(20) EMA가 장기(50) EMA 위에 있는 **정배열(상승 추세)** 상태인지 확인합니다. 현재가가 EMA 20보다 높아야만 진입을 허용합니다.
* **ADX (평균방향성지수, 14):** 추세의 '강도'를 측정합니다. ADX 값이 **28 이상**일 때만 시장에 뚜렷한 방향성이 있다고 판단하고 횡보장에서는 진입을 차단합니다.

### 2. 정밀 진입 셋업 (15분 봉 기준)
상위 추세가 확인되면, 변동성 돌파 전략을 통해 타점을 잡습니다.
* **Highest_40 돌파:** 과거 40개 캔들의 '최고점'을 돌파할 때 강한 매수세가 붙었다고 판단하여 **SETUP(진입 준비)** 상태로 전환합니다.
* **돌파 안착 확인:** 가격이 돌파 후 바로 무너지지 않고, 해당 기준가를 지지하며 캔들이 마감될 때 최종 **POSITION(매수)**에 진입합니다.

### 3. 수학적 리스크 관리 (ATR 기반)
* **ATR (평균진폭):** 시장의 변동성을 수치화한 지표입니다. 변동성이 클 때는 목표가와 손절가를 넓게, 작을 때는 좁게 자동 조정합니다.
* **동적 포지션 사이즈 (1% Rule):** 매번 똑같은 금액을 사는 것이 아니라, 손절 시 **총자산의 1%만 손실**을 보도록 현재 ATR 수치에 비례하여 매수 금액을 자동 계산합니다.

### 4. 청산 (익절 및 손절) 로직
* **1차 익절 (+2.0 ATR):** 목표 수익에 도달하면 보유 물량의 30%를 즉시 매도하여 수익을 확정 짓습니다. 이후 손절선은 '본절가 + 0.5 ATR'로 끌어올려(Trailing Stop) **절대 손실이 나지 않는 상태**로 만듭니다.
* **2차 익절 (+8.0 ATR):** 강력한 상승이 나왔을 때 전량 매도하여 수익을 극대화합니다.
* **칼손절 (-1.5 ATR):** 예측이 틀렸을 경우 미련 없이 전량 매도 후, **3시간 동안 매매를 쉬며(쿨다운)** 뇌동매매를 방지합니다.

### 5. 서킷 브레이커 (Flash Crash 방어)
* 5분 봉 기준 연속된 캔들에서 **-5% 이상의 비정상적인 급락**이 감지되면 봇이 즉시 매매를 중단하고 **6시간 동안 신규 진입을 전면 차단**하여 계좌가 녹는 것을 방지합니다.

## 📱 텔레그램 (Telegram) 원격 제어

텔레그램 봇 API가 연동되어 있어, 밖에서도 스마트폰으로 봇의 상태를 실시간 확인하고 명령을 내릴 수 있습니다.

* **`/status`**: 현재 봇의 상태(IDLE/SETUP/POSITION), 평단가, 1차 익절 여부 및 실시간 수익률을 조회합니다.
* **`/balance`**: 현재 업비트 계좌의 KRW(원화) 잔고, 보유 BTC 수량 및 총 추정 자산을 확인합니다.
* **`/sell_all`**: **[긴급 명령어]** 폭락이 예상될 때 명령을 내리면, 즉시 보유 중인 모든 BTC를 시장가로 던지고 포지션을 초기화합니다.
* **`/stop`**: 봇 프로세스를 안전하게 종료합니다. (재시작은 서버에서 PM2로 수행해야 합니다)
* **`/all`**: 모든 사용 가능한 명령어 리스트를 확인합니다.
